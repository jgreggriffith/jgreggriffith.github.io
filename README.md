# greggriffith.com

Source for the personal website of Greg Griffith, served by GitHub Pages.

- `index.html`: Home page, including the structured data (JSON-LD) that identifies Greg to search engines.
- `blog/`: Writing. Each post lives in its own folder, `blog/<slug>/index.html`.
- `robots.txt`, `sitemap.xml`: Search engine files. Add each new post to the sitemap.

Changes go through pull requests. When anything changes, update the "Last updated" stamp and `dateModified` on the home page, and `lastmod` in the sitemap.
